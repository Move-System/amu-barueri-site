Política de Privacidade

Esta Política de Privacidade descreve como o aplicativo AMU, desenvolvido por AMZ Tecnologia Governamental, coleta, utiliza, armazena e protege as informações dos usuários.

1. Informações Gerais

Esta Política de Privacidade descreve como o aplicativo AMU, desenvolvido por AMZ Tecnologia Governamental, coleta, utiliza, armazena e protege as informações dos usuários.

Em caso de dúvidas, entre em contato pelo e-mail: devamzinfotec@gmail.com.

2. Dados Coletados

O aplicativo pode coletar os seguintes dados:

  • Nome completo
  • Endereço de e-mail
  • Informações de autenticação
  • Dados de uso (logs, tempo de acesso, interações)
  • Endereço IP
  • Identificadores do dispositivo

Esses dados são coletados de forma direta (quando fornecidos pelo usuário) ou automática (por meio de ferramentas de análise).

3. Finalidade do Uso dos Dados

Os dados coletados são utilizados para:

  • Permitir autenticação e acesso à conta;
  • Garantir segurança da aplicação;
  • Melhorar funcionalidades e experiência do usuário;
  • Cumprir obrigações legais.

4. Compartilhamento de Dados

O aplicativo pode utilizar serviços de terceiros para funcionamento adequado, incluindo:

  • Google Firebase (armazenamento e autenticação);
  • Serviços de hospedagem em nuvem;
  • Ferramentas de monitoramento e análise.

Esses serviços podem processar dados conforme suas próprias políticas de privacidade.

5. Armazenamento e Segurança

Os dados são armazenados em servidores seguros, com utilização de:

  • Criptografia de dados;
  • Controle de acesso restrito;
  • Boas práticas de segurança da informação.

Apesar das medidas adotadas, nenhum sistema é totalmente isento de riscos.

6. Retenção dos Dados

Os dados serão mantidos enquanto:

  • A conta do usuário estiver ativa;
  • Forem necessários para cumprimento de obrigações legais;
  • Houver necessidade legítima para operação do serviço.

O usuário pode solicitar exclusão a qualquer momento.

7. Direitos do Usuário

Nos termos da Lei Geral de Proteção de Dados (Lei nº 13.709/2018), o usuário pode solicitar:

  • Confirmação da existência de tratamento;
  • Acesso aos dados;
  • Correção de dados incompletos ou desatualizados;
  • Exclusão de dados pessoais;
  • Revogação do consentimento.

Solicitações podem ser feitas via e-mail informado acima.

8. Transferência Internacional de Dados

Alguns serviços utilizados podem armazenar dados fora do Brasil. Nesses casos, são adotadas medidas adequadas de proteção conforme legislação aplicável.

9. Alterações nesta Política

Esta Política pode ser atualizada periodicamente. Recomendamos que o usuário revise esta página regularmente.
